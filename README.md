mrrt - My rust ray tracer
Моя реализация трассировки пути с использованием вычислительных шейдеров и wgpu. Для него реализовал bvh для отрисовки большого количества полигонов средствами. Для его формирования использовал rust. 
Для примера создал сцену с корнеллской коробкой, сюзанной, шаром и драконом. 
В будущем планирую написать шумоподавление для существенного улучшения качества картинки. 

Для запуска: cargo run
